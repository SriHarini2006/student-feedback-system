About The Project

Digital Feedback for Modern Institutions

The Student Feedback Management System helps colleges collect, organize, and inspect student reviews digitally. By replacing paper forms and disorganized surveys, it establishes a transparent channel between students and faculty.

Built as a real-world demonstration of modern DevOps, this application pairs a lightweight Python Flask backend with automated Continuous Integration & Continuous Delivery using Git, Jenkins, and Docker.
